How it works
01 · SIMULATE
Agent-based swarm simulator
Recon, four entry vectors (exploits, AI phishing, supply chain, hijacking the company's own AI agents), lateral spread, detection, detonation, backups, recovery, losses and liquidity, in 2-hour steps.
02 · LEARN
Gradient-boosted surrogates
Monotonic models trained on 600,000 simulated campaigns. Recovery and loss are a two-mode mixture (detonated vs contained). Collapse uses exact soft labels.
03 · DECIDE
Drivers, actions, plans
Millisecond predictions make what-if analysis possible: risk drivers, 16 ranked interventions, a combined plan and threat curves.
Limits

No real AI-swarm incident data exists yet. Outcomes rest on the simulator's documented assumptions, so read them as informed relative estimates, not actuarial prices.

Thinly capitalised companies near the collapse threshold can be under-predicted by a few points. For the weakest profiles, recovery time and loss run low too. Run a simulation to check any single company precisely.
